## تشغيل الكود
```
g++ -std=c++11 DHCP_Simulation.cpp -o dhcp
./dhcp        (على ويندوز: dhcp.exe)
```

## فكرة الكود
عندنا 3 كلاسات، كل واحد ليه شغلة واحدة:
1. **IPPool** : مخزن العناوين (192.168.1.10 → .13) ومين واخد كل عنوان (بالـ MAC). فاضي = العنوان متاح.
2. **DhcpServer** : فيه IPPool، وبيرد على الرسايل:
   - `handleDiscover` : يختار عنوان فاضي يعرضه (OFFER) أو يرجّع "" لو مفيش.
   - `handleRequest`  : يأكد (ACK) لو العنوان لسه متاح، وإلا NAK.
   - `handleRelease`  : يحرر العنوان.
3. **Client** : الجهاز (PC). `requestIp()` بتنفذ الـ DORA كاملة مع السيرفر.

الـ `main()` بس بتعرض القائمة وتقرأ الاختيار وتنادي على الكائنات.

## القائمة
| الاختيار | بيعمل إيه |
|---|---|
| 1 | Test case 1: IP متاح (PC1 ياخد .10) |
| 2 | Test case 2: مفيش IP (4 أجهزة تملّا الـ pool والخامس يفشل) |
| 3 | توصيل جهاز جديد |
| 4 | عرض حالة الشبكة |
| 5 | فصل جهاز (Release) |
| 0 | خروج |
| غير كده | "Invalid choice" |

القائمة دي بتغطي نفس حالات الفلوتشارت المطلوب (IP متاح / مفيش IP / اختيار غلط) وبتزود عليها.

## أسئلة ممكن الدكتورة تسألها
- **ليه كلاسات؟** عشان كل جزء ليه مسؤولية واحدة وأسهل في الفهم والتعديل.
- **الفرق بين OFFER و ACK؟** OFFER السيرفر بيعرض عنوان، ACK بيأكد إنه اتسجل للجهاز.
- **امتى NAK؟** لو الجهاز طلب عنوان مش متاح لحد تاني (الكود بيدعمها بس مش بتحصل في السيناريو العادي).
- **الـ MAC ليه؟** السيرفر بيعرف الجهاز بيه، ولو نفس الجهاز طلب تاني بياخد نفس العنوان.
- **ليه `readNumber` بتقرأ سطر كامل؟** عشان لو كتب المستخدم حروف أو سطر فاضي البرنامج ما يهنجش.
- **حدود المشروع؟** مفيش شبكة حقيقية، ومفيش Lease time أو Renew.
